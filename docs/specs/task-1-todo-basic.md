# Task 1 規格：待辦清單基本功能

> 練習專案，用來試跑半自動協作流程。使用者已核可本計畫（2026-10-02）。

## 產品目標

使用者打開一個網頁，可以新增待辦、看到清單、勾選完成。資料只存在畫面上，重新整理就清空（本 Task 不做儲存）。

## 行為與驗收標準

1. 在輸入框輸入文字後，按「新增」或按 Enter，待辦出現在清單最下方，輸入框清空。
2. 新增時去掉前後空白；空白或只有空格的內容不能新增，輸入框下方顯示「請輸入待辦內容」。之後成功新增時提示消失。
3. 每筆待辦有勾選框；勾選後文字加刪除線並變淡，再按一次恢復。
4. 清單是空的時候顯示「還沒有待辦」。
5. 鍵盤可以完成所有操作（Tab 到輸入框、Enter 新增、Tab 到勾選框、空白鍵勾選），焦點要看得見。

## 技術約束

- 單檔網頁：`index.html`（畫面）＋ `todo.js`（純邏輯，ES module，不碰 DOM）＋ `todo.test.js`（Node 內建 `node:test`）。不安裝任何套件。
- `todo.js` 提供純函式：`addTodo(list, text)`、`toggleTodo(list, id)`。不修改傳入的陣列，回傳新陣列。空白內容時 `addTodo` 丟出 `Error`，訊息為 `EMPTY_TEXT`。
- 畫面用 Tailwind CDN；在 `index.html` 檔頭以 CSS 變數定義設計代幣。

## 視覺方向（練習用，Claude 指定）

- 淺色、安靜、單一主色：青綠 `#0f766e`；灰階三層。
- 字體：Noto Sans TC（Google Fonts）。
- 內容寬度上限 560px 置中；手機 375px 寬不可出現橫向捲動。
- 一處微動效：新增的待辦淡入（150–200ms），尊重 `prefers-reduced-motion`。
